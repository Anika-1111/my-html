# Types of Flowers Website

This is a simple website about different types of flowers.

## About the Project

The website includes information about flowers such as Rose, Sunflower, Tulip, Lotus, and Jasmine. It also includes flower descriptions, lists, tables, interesting facts, flower care tips, and useful links.

## Features
- Flower image
- Information about flowers
- Ordered and unordered lists
- Flower description list
- Flower information table
- Flower care tips
- Links to learn more about flowers
- Favourite flower form
